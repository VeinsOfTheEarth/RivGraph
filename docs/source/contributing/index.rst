============
Contributing
============

If you think you're not skilled or experienced enough to contribute, think again.
We agree wholeheartedly with the sentiments expressed by this
`Imposter syndrome disclaimer <https://github.com/Unidata/MetPy#contributing>`_.

We welcome feature requests, bug reports, code contributions, and documentation improvements.
The simplest way to contribute is to open an
`issue <https://github.com/VeinsOfTheEarth/RivGraph/issues>`_ or submit a pull request.

For larger code changes, it is especially helpful to open an issue first so the design and scope can be discussed before implementation.
